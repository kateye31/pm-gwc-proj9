          Project charter

          Ship a playable 4-chamber Java escape room and demo it live on Thursday, Nov 12.

          Done means

          • A new player escapes all 4 chambers in under 15 minutes
          • Every puzzle has two hints and an explanation
          • 4 playtesters outside the team tried it before Nov 9
          • Every student can explain the part they built

          In scope

          • Knight select, 4 chambers, escape screen
          • Computer browsers only

          Out of scope

          • Phones and tablets
          • Accounts, saved progress, leaderboards

          What each chamber teaches

          Based on Sanjana's research: one OOP concept per room, short explanations, real Java snippets, hints that teach instead of giving answers, and polymorphism saved for the final boss.

          ChamberConcept (Sanjana's map)Learn it
          The MazeClasses and objects; constructors and methods. "A Knight class is the blueprint, each knight is an object"Programiz: classes and objects
          Alchemy LabMethods, return values and encapsulation: private fields, public methodsProgramiz: encapsulation
          Hall of IllusionsInheritance: Wizard and Knight share a Character parentProgramiz: inheritance
          The Final DoorPolymorphism, the final boss: different objects answer the same method call. Then explain it in your own wordsProgramiz: polymorphism

          Platforms from Sanjana's research

          Codecademy: Learn JavaSmall lessons, one concept at a time
          Programiz PROExplanations, exercises, quizzes and projects
          CodeQuestMakes Java practice game-like with challenges and rewards
